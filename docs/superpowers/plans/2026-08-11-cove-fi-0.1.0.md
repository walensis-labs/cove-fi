# cove-fi 0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the Python reference engine to TypeScript at oracle-gated parity and ship `@walensis/cove-fi` 0.1.0: engine + TOML plan file + CLI + stdio MCP server.

**Architecture:** pnpm workspace mirroring cove-for-ynab (one package for now). A pure engine (`model.ts` + `engine.ts`) ported line-by-line from `~/develop/cove-fi-python-reference/cove_fi/`, wrapped by a `Session` layer that CLI and MCP both call. Parity is proven by diffing TS engine output against a JSON dump of the Python engine's rows on the same plan (< $1/cell), not by re-deriving the PL comparison.

**Tech Stack:** TypeScript 5.5 (strict, NodeNext, ES2022), pnpm 11, tsup, vitest, smol-toml, commander, @modelcontextprotocol/sdk, changesets.

## Global Constraints

- Node `>=20`; CI runs Node 22 (mirror cove-for-ynab `ci.yml`).
- Package `@walensis/cove-fi`, MIT, `type: "module"`, bin `cove-fi`. Version starts `0.0.0`; the Task 11 changeset releases it as 0.1.0.
- Runtime deps ONLY: `smol-toml`, `commander`, `@modelcontextprotocol/sdk`, `zod` (peer of the MCP SDK). Everything else is dev.
- tsconfig base (copy verbatim): `target ES2022, module NodeNext, moduleResolution NodeNext, strict, declaration, skipLibCheck, forceConsistentCasingInFileNames, noUncheckedIndexedAccess`.
- **PARITY RULE (overrides taste):** port `engine.py` arithmetic in the EXACT operation order, including its quirks — the hardcoded `225_000` salary base, `int(12 * frac)` mortgage months, 4-iteration pretax convergence with `< 1.0` threshold, coast trigger using literal `4 *` (not `coast_multiple`), growth as `1 + r * frac`. Do NOT fix, refactor, or "improve" any formula in 0.1.0. Cleanups happen post-parity as calibration work with baseline updates.
- **PRIVACY RULE:** `private/` is gitignored and stays that way; no real dollar figures anywhere in the public tree. Before any commit touching docs, run the tripwire: `grep -rInE "$(cat private/tripwire.txt)" --exclude-dir=private --exclude-dir=.git --exclude-dir=node_modules .` and require zero hits.
- **Client-agnostic MCP:** no Anthropic-specific behavior in server code.
- Engine internals are nominal dollars; today's-$ conversion only at reporting edges (`session.ts`).

- [ ] **Step 1: Write the dump script**

`~/develop/cove-fi-python-reference/dump_parity.py`:
```python
"""Dump the private fixture plan + engine rows for TS parity testing."""
import dataclasses, json, sys

from cove_fi.engine import run
from cove_fi.fixture_aj import PLAN

OUT = sys.argv[1] if len(sys.argv) > 1 else "../cove-fi/private"

def clean(o):
    if dataclasses.is_dataclass(o):
        return {k: clean(v) for k, v in dataclasses.asdict(o).items()}
    if isinstance(o, dict):
        return {k: clean(v) for k, v in o.items()}
    if isinstance(o, list):
        return [clean(v) for v in o]
    if hasattr(o, "value"):   # Enum
        return o.value
    return o

with open(f"{OUT}/plan_aj.json", "w") as f:
    json.dump(clean(PLAN), f, indent=1)

rows = [{k: v for k, v in dataclasses.asdict(r).items() if k != "detail"}
        for r in run(PLAN)]
with open(f"{OUT}/rows_aj.json", "w") as f:
    json.dump(rows, f, indent=1)
print(f"wrote {OUT}/plan_aj.json and rows_aj.json ({len(rows)} rows)")
```

Note: `dataclasses.asdict` already converts nested dataclasses to dicts; `clean` handles the `TaxType` str-Enum values (they serialize as `"taxable"` etc. because TaxType extends str — verify in output).

```ts
export interface Account { name: string; tax: TaxType; balance: number; growth?: number | null; liquid?: boolean; penalty_age?: number; penalty_rate?: number; rmd?: boolean; basis?: number | null; }
export interface Income { name: string; amount: number; start: number; end: number; taxable?: boolean; reduces_by_pretax?: boolean; }
export interface SocialSecurity { pia_monthly: number; claim_year: number; haircut?: number; taxable_fraction?: number; }

export interface Mortgage { balance: number; rate: number; payment_monthly: number; }
export interface House { value: number; appreciation: number; mortgage?: Mortgage | null; property_tax_rate?: number; insurance_rate?: number; maintenance_rate?: number; hoa_monthly?: number; }
```

- [ ] **Step 4: Port engine.py → engine.ts, line by line**

Open `~/develop/cove-fi-python-reference/cove_fi/engine.py` beside the editor and transcribe `run()` preserving structure and operation order exactly. A faithful-port checklist of the traps:

- `overrides` merge: `const a: Assumptions = { ...plan.assumptions, ...overrides }`.
- `infl = (y) => (1 + a.inflation) ** (y - a.start_year)` — use `**`, fine in ES2022.
- Balances/basis/mortgage state as `Map<string, number>` or plain objects — match Python dict iteration order by iterating `plan.accounts` arrays, never object key order.
- Income/SS sums, expense loop with `grow$` convention: `g ** (y - e.start)` when `nominal_at_start` else `g ** (y - a.start_year)` where `g = 1 + a.inflation + (e.growth_over_inflation ?? 0)`.
- Mortgage months: `for (let m = 0; m < Math.trunc(12 * frac); m++)` — `int()` truncates; do NOT round.
- 529-funded expenses list processed AFTER house block, adding shortfall to `exp`.
- Working-year block only when `y <= last_work_year` where `last_work_year = a.retirement_year - 1`.
- Convergence loop: exactly `for (let iter = 0; iter < 4; iter++)`, break condition `Math.abs(new_pretax - pretax) < 1.0` AFTER assigning like Python does (note Python assigns on break AND at loop end — replicate: compute new trio, if `|new_pretax - pretax| < 1` assign+break else assign+continue).
- COAST sentinel: `c.end === COAST`, `c.start === COAST`; skip/window logic identical.
- `want` for pct_of_income uses the literal `225_000 * f` salary base; employer match logic identical including the odd `frac < 1` ternary and the `amt > 0` guards.
- `want *= frac` BEFORE clamping to `available`.
- Surplus: `if (surplus > 0) exp += surplus`.
- Taxable contributions increase `basis` by contribution amount (not match).
- Dividends AFTER the working/else block, on CURRENT taxable balances, `* frac`, taxed at cap gains.
- Retirement: SS tax added first; `need = exp + taxes - row.income`; drawdown order is the literal array `[TAXABLE, HSA, TRADITIONAL, ROTH, CASH]` over `plan.accounts` in declaration order; trad draws add `take * ord_rate` to BOTH `remaining` and `taxes` (the gross-up spiral — keep it, it's open item 1); taxable draws compute `gain = max(1 - basis/bal, 0)` BEFORE mutating basis, then `basis *= (1 - take/bal)`.
- RMD block: `age >= 73`, divisor `RMD_TABLE[Math.min(age, 100)] ?? 6.4`, forced net of `trad_taken`.
- Growth: `bal *= 1 + r * frac` for every account, AFTER withdrawals.
- Net worth: liquid sums accounts with `liquid !== false`; house value uses exponent `(y - a.start_year + 1)`; `liquid_net_worth = liquid - mort_bal` (note: consumer debt would subtract here too if modeled — v0.2 has none).
- Coast detection: trailing-3 average of `row.expenses` pushed AFTER the row completes; trigger `liquid_net_worth >= 4 * avg` with the LITERAL 4.

Export `run` and re-export everything from `index.ts`: `export * from "./model.js"; export * from "./engine.js";`

```ts
import { run } from "../src/engine.js";
import { planFromJson } from "../src/planjson.js";
import { syntheticPlan } from "./helpers/synthetic.js";

const sum = (xs: number[]) => xs.reduce((a, b) => a + b, 0);

describe("conventions", () => {
  const plan = syntheticPlan();
  const rows = run(plan);
  const byYear = new Map(rows.map(r => [r.year, r]));

  it("1: LNW excludes 529 and house; NW includes both", () => {
    // recompute year-1 identity from a single-account probe plan instead of
    // reimplementing the engine: with one liquid account, no house, no flows,
    // NW === LNW === balance * (1 + ret * frac)
    const probe = planFromJson({ birth_year: 1990,

    expect(r!.liquid_net_worth).toBeCloseTo(1000 * 1.07, 6);
    // and on the full plan: NW - LNW === 529 balance + house value (year 1)
    const r0 = rows[0]!;
    expect(r0.net_worth).toBeGreaterThan(r0.liquid_net_worth);
  });

  it("2: waterfall is cash-flow constrained — never withdraws to fund rungs", () => {
    const workRows = rows.filter(r => r.year < plan.assumptions.retirement_year);
    // 529-funded education years DO withdraw from the 529; exclude them
    const eduYears = new Set([2040, 2041, 2042, 2043]);
    for (const r of workRows.filter(r => !eduYears.has(r.year)))
      expect(r.withdrawals, `year ${r.year}`).toBe(0);
  });

  it("3: surplus is spent — income identity holds every working year", () => {
    for (const r of rows.filter(r => r.year < plan.assumptions.retirement_year)) {
      // dividends tax is the only wedge: income - taxes - contributions - expenses
      // must be ~0 (surplus folded into expenses) when cash flow is positive
      const resid = r.income - r.taxes - r.contributions - r.expenses;
      expect(resid, `year ${r.year}`).toBeLessThan(1);
    }
  });

  it("4: nominal_at_start (grow$) compounds from plan start vs own start", () => {
    const g = (p: ReturnType<typeof syntheticPlan>, nominal: boolean) =>
      run(planFromJson({ ...p, contributions: [], house: null, incomes: [],
        social_security: [],
        expenses: [{ name: "e", amount: 1000, start: 2030, end: 2030,
                     nominal_at_start: nominal }],
        assumptions: { ...p.assumptions, start_year: 2026, end_year: 2030,
          retirement_year: 2099, dividend_rate: 0 },
        accounts: [{ name: "c", tax: "cash", balance: 1e9, growth: 0 }] }))
        .at(-1)!.expenses;
    // nominal_at_start: 1000 * 1.03^(2030-2030) = 1000
    expect(g(plan, true)).toBeCloseTo(1000, 6);
    // today's-$: 1000 * 1.03^(2030-2026)
    expect(g(plan, false)).toBeCloseTo(1000 * 1.03 ** 4, 6);
  });

  it("5: pretax rungs reduce the tax base (converged)", () => {
    const r27 = byYear.get(2027)!;
    // gross 100k grown one year; 401k+HSA limits pretax -> taxes strictly less
    // than gross * (income_tax + local_tax)
    expect(r27.taxes).toBeLessThan(r27.income * 0.31);
  });

  it("first_year_fraction scales year one", () => {
    const full = run({ ...plan, assumptions: { ...plan.assumptions, first_year_fraction: 1.0 } });
    expect(rows[0]!.income).toBeCloseTo(full[0]!.income * 0.5, 6);
  });

  it("deterministic: same input, same output", () => {
    expect(run(syntheticPlan())).toEqual(rows);
  });
});
```
